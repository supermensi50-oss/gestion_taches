gestion des tâches

c'est une petite application python qui marche dans la console. elle sert à gérer des tâches de tous les jours. chaque tâche a un numéro et un titre. tout le code est dans le fichier main.py.

fonctionnalités :

le menu se répète tant qu'on ne choisit pas 0.

- 1 : ajouter une tâche (le programme demande le titre, si le titre est vide il affiche une erreur)
- 2 : afficher les tâches avec leur numéro (il y a un message si la liste est vide)
- 3 : rechercher une tâche avec un mot-clé (il y a un message si rien n'est trouvé)
- 0 : quitter le programme
- autre choix : message d'erreur

étapes réalisées :

1. nous avons créé le dossier du projet et le fichier main.py

3. nous avons fait le menu avec une boucle while
4. nous avons fait l'ajout d'une tâche
5. nous avons fait l'affichage des tâches
6. nous avons fait la recherche par mot-clé
7. nous avons ajouté le message d'erreur pour les mauvais choix
8. nous avons testé le programme avec le bouton run python file
9. nous avons écrit ce fichier de documentation

méthode d'exécution :

1. ouvrir le dossier du projet dans vs code (il faut avoir python et l'extension python)
2. ouvrir le fichier main.py
3. cliquer sur le bouton run python file (le triangle en haut à droite)
4. dans le terminal en bas, taper un choix (1, 2, 3 ou 0) puis appuyer sur entrée
5. taper 0 pour quitter
